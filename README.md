# Дом 9 · Красная Пресня — кабинет собственника

Сайт: https://lychits.github.io/dom9/

- `index.html` — кабинет (одна страница, без сборки).
- `data/public.json` — открытая часть без персональных данных. **Не править вручную**: файл публикует Apps Script из Google Drive («Кабинет дома 9 — сайт / Данные (редакции)») при каждом изменении источников.
- Закрытые данные (операции, первичка, документы, состав совета) в репозиторий не попадают — сайт получает их с сервера Apps Script после входа по коду.

Роли: гость → собственник (код на e-mail из таблицы «Доступ») → совет дома → администратор (код + PIN).
